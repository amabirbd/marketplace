# Demo photography

The six bundled product images were generated for LocalLoop using OpenAI's image-generation tool on 2026-11-17. They depict fictional goods and are not photographs of real sellers' belongings. No external image host is required at runtime.

The source images were resized to 1,000 × 1,000 JPEGs at quality 82. Together they occupy roughly 855 KB. Thirty fictional listings reuse these six product photographs to keep the initial demo small; richer unique inventory can be added later.

System typography is used so the demo has no remote font dependency. Bangla renders through the device's font fallback. Native font rendering still needs device verification.
