# LocalLoop walkthrough — 60–90 seconds

**0–10 seconds:** “LocalLoop is a neighborhood marketplace for Dhaka. This demo runs without an account or backend.” Open Explore demo.

**10–25 seconds:** “I can search in English or Bangla, filter by neighborhood and condition, and compare prices in taka.” Select Furniture, save a chair, and open its details.

**25–40 seconds:** “Location stays approximate. Messaging uses the same feature interface as the rest of the app.” Send a message. Point to the Simulated label: “This is a fictional reply, entirely local.”

**40–65 seconds:** “The sell flow validates each step and preserves unfinished drafts.” Open Sell, enter details, use a demo photo, and publish locally. “Refreshing preserves the listing and its images.”

**65–80 seconds:** “The demo has failure controls so I can show optimistic rollback and retry behavior. A retry reuses the original message ID.” Open Profile and show the controls, theme, and language options.

**80–90 seconds:** “The live Supabase adapter is the next milestone. Today the browser journey is tested; native runtime support and database security are not yet verified.” Show Reset demo.

For a shorter tour, omit publishing and finish after the labeled chat reply. Do not describe simulated chat as realtime or local checks as database authorization.
